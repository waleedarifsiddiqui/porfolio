# Waleed Arif Portfolio

A personal portfolio built with Next.js, React, and Tailwind CSS. It uses a
dark, two-column layout inspired by Allison Yancy's portfolio and contains
Waleed's profile, experience, and projects.

## Live site

Visit [waleed-arif.vercel.app](https://waleed-arif.vercel.app).

## Run locally

```powershell
npm install
npm run dev
```

Open the local URL printed by `npm run dev` (usually port 3000).

## Update content

Edit `src/data/portfolio.ts` to update Waleed's projects and work experience.
The homepage layout and section styling are in `src/app/page.tsx`.

## Deploy

Push this project to your own GitHub repository and import that repository into
Vercel. It does not need Allison's Prismic content repository.
